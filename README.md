# SBU Robotics Lab — Interns

This repository contains the training materials, weekly exercises, and projects for interns at the **SBU Robotics Lab**.

The program is designed to build practical skills in **robotics software development** and gradually prepare interns for robotic manipulation and task-based competitions such as **RoboCup@Work**.

## Structure

Each week has its own directory containing the corresponding exercise or project:

```text
├── week01/
├── week02/
├── week03/
└── ...
```

Each weekly directory may contain:

* Exercise description
* Source code
* Documentation
* Configuration files
* Example outputs

## Platform

The main robotic platform used throughout the program is:

* **TurtleBot3 Waffle**
* **OpenMANIPULATOR-X**
* **ROS 2 Humble**
* **Ubuntu 22.04**

The exercises will gradually cover topics such as:

* Linux and development tools
* Python
* Git
* ROS 2
* Robot control
* Navigation
* Perception
* Manipulation
* Task execution
* Simulation
* Integration of robotic subsystems

## Goal

The goal of the program is not only to learn individual technologies, but to gradually develop the ability to build and integrate complete robotic systems for real-world tasks.
